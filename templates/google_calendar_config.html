Configuração Necessária

Para sincronizar com o Google Calendar da sua esposa, você precisa configurar as credenciais primeiro.

Passo a Passo da Configuração
  1. Acesse o Google Cloud Console: Abrir Console
  2. Crie um projeto novo ou selecione um existente
  3. Ative a Google Calendar API:
    Navegue para "APIs e Serviços" > "Biblioteca" > "Google Calendar API" > "Ativar"
  4. Crie credenciais OAuth 2.0:
    "APIs e Serviços" > "Credenciais" > "Criar Credenciais" > "ID do cliente OAuth"
  5. Escolha "Aplicativo para desktop"
  6. Baixe o arquivo JSON e renomeie para credentials.json
  7. Coloque o arquivo na pasta do projeto e reinicie a aplicação
Totalmente Gratuito!

A API do Google Calendar é 100% gratuita para uso pessoal, com limite de 1.000.000 requisições por dia (mais que suficiente para o uso da clínica).
